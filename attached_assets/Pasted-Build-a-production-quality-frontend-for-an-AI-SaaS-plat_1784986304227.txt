Code Quality Requirements

- Create reusable components.
- Follow a scalable folder structure.
- Use reusable cards, dialogs, tables, forms, badges, buttons, charts, and modals.
- Keep business logic separated from UI.
- Use mock JSON data instead of APIs.
- Use TypeScript interfaces everywhere.
- Add comments indicating where future backend APIs will connect.
- Use placeholder service files that can later be replaced with real APIs.

DO NOT:
- Change the UI later.
- Generate backend code.
- Create Express/FastAPI/Node services.
- Add databases.
- Add authentication logic.

This frontend will later be connected to a backend generated separately, so make the architecture future-proof and maintain a pixel-perfect UI.
